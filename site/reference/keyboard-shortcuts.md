# Keyboard shortcuts

On Windows and Linux, use <kbd>Ctrl</kbd> in place of <kbd>⌘</kbd>. DimSum hasn't been tested on those systems yet.

## Everywhere

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd><kbd>O</kbd> | Open a file |
| <kbd>⌘</kbd><kbd>P</kbd> | Go to File…, which also works while a terminal has focus |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>F</kbd> | Find in Files |
| <kbd>⇧</kbd><kbd>F10</kbd> or the menu key | Open the context menu for the focused item |

## Composer

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd><kbd>Enter</kbd> | Send the prompt |
| <kbd>Enter</kbd> | New line |

The terminal above the composer is the agent's own CLI, so its shortcuts are the CLI's. To switch the mode, use the composer's **Mode** picker, and DimSum sends the CLI's own key or command for you.

## Editor

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd><kbd>S</kbd> | Save |
| <kbd>⌘</kbd><kbd>L</kbd> | Send the selection, or the current line, to an agent |
| <kbd>⌘</kbd><kbd>F</kbd> | Find |
| <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Undo / redo |

## Files panel

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd><kbd>X</kbd> / <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>V</kbd> | Cut, copy and paste files |
| <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Undo or redo the last file operation |
| <kbd>Esc</kbd> | Cancel a new name or a rename |

You can't rebind shortcuts yet.
